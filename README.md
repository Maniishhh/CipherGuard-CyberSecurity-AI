# 🛡️ CipherGuard AI

> An AI-powered cybersecurity platform that combines Privacy Risk Analysis, Military-Grade File Encryption, Secure Password Generation, and Client-Side Security into a single web application.

---

## 🚀 Overview

CipherGuard AI is a modern cybersecurity suite designed to help users protect sensitive information through AI-powered privacy analysis and advanced cryptographic techniques.

The application enables users to:

- 🔍 Detect Personally Identifiable Information (PII)
- 🔐 Encrypt files using AES-256-GCM encryption
- 🔓 Decrypt encrypted files securely
- 🔑 Generate cryptographically secure passwords
- 🛡️ Protect user data with multiple browser-based security layers

All sensitive operations are performed **client-side**, ensuring that user files and passwords never leave the device.
